# 行为树决策引擎：让游戏 AI 学会复杂任务编排

> 状态机能处理"打怪→拾取→售卖"的简单流程，但当任务变成"血少了先吃药→背包满了先挑贵的卖→顺路捡宝箱"这种多优先级交错时，状态机就会失控。本文引入**行为树（Behavior Tree）**——游戏工业界最流行的 AI 决策方案，用 Python 从零实现一个可复用的决策引擎。

## 一、为什么状态机不够用

| 场景 | 状态机 | 行为树 |
|------|--------|--------|
| 流程固定 | 简单直观 | 略复杂 |
| 多目标优先级 | 状态爆炸 | 天然支持 |
| 条件打断/恢复 | 难写 | 内置中断 |
| 模块复用 | 差 | 节点可复用 |
| 调试可视化 | 一般 | 好 |

> 结论：沙盒里单线程打怪用状态机足够；一旦代理要"同时考虑血量、背包、距离、价值"，行为树是更优解。

## 二、行为树的四类节点

行为树是一棵"从上到下、从左到右"求值的树，节点类型：

```
行为树节点
├── 控制节点（决定走哪条分支）
│   ├── Selector（选择器）   : 从左到右找第一个成功的子节点
│   ├── Sequence（序列）    : 全部成功才算成功，失败即停
│   └── Parallel（并行）    : 同时跑多个子节点
├── 装饰节点（Decorator）    : 反转/限次/冷却等包装
├── 条件节点（Condition）    : 判断"是否满足"，返回成功/失败
└── 行为节点（Action）       : 真正执行动作，返回成功/失败/运行中
```

### 核心：三种返回值

```python
class Status:
    SUCCESS = "success"
    FAILURE = "failure"
    RUNNING = "running"   # 还没做完，下次继续
```

> RUNNING 是行为树的灵魂：长动作（走一段路、打一个怪）可以"分帧执行"，被打断还能安全中止。

## 三、Python 实现行为树

### 1. 节点基类

```python
from abc import ABC, abstractmethod

class Node(ABC):
    def __init__(self, name=""):
        self.name = name
        self.children = []

    def add_child(self, child):
        self.children.append(child)
        return self

    @abstractmethod
    def tick(self, blackboard):
        """执行一次，返回 Status"""
        pass
```

### 2. 组合节点

```python
class Selector(Node):
    """选择器：依次尝试子节点，找到第一个成功的"""
    def tick(self, bb):
        for child in self.children:
            s = child.tick(bb)
            if s != Status.FAILURE:   # SUCCESS 或 RUNNING 都返回
                return s
        return Status.FAILURE

class Sequence(Node):
    """序列：全部成功才成功，中途失败即停止"""
    def tick(self, bb):
        for child in self.children:
            s = child.tick(bb)
            if s != Status.SUCCESS:
                return s
        return Status.SUCCESS
```

### 3. 条件与动作

```python
class Condition(Node):
    def __init__(self, fn, name=""):
        super().__init__(name)
        self.fn = fn   # fn(bb) -> bool

    def tick(self, bb):
        return Status.SUCCESS if self.fn(bb) else Status.FAILURE

class Action(Node):
    def __init__(self, fn, name=""):
        super().__init__(name)
        self.fn = fn   # fn(bb) -> Status

    def tick(self, bb):
        return self.fn(bb)
```

### 4. 黑板上位（Blackboard）

行为树节点之间通过"黑板"共享数据：

```python
class Blackboard(dict):
    """就是普通 dict，但集中管理全局状态"""
    pass
```

## 四、实战：打怪代理的行为树

用行为树重写我们的打怪沙盒 AI：

```
行为树（根）
└── Selector（优先级从高到低）
    ├── [紧急] 血量低 → 跑路回血
    │   └── Sequence: 血<30% → 撤退到安全点 → 等待回血
    ├── [紧急] 背包满 → 回城售卖
    │   └── Sequence: 背包满 → 去商店 → 卖掉背包
    ├── [常规] 附近有掉落 → 拾取
    │   └── Sequence: 发现掉落 → 走过去 → 拾取
    ├── [常规] 发现敌人 → 战斗
    │   └── Sequence: 发现敌人 → 追击 → 攻击
    └── [默认] 巡逻探索
        └── 向随机点移动
```

### 代码

```python
def build_tree():
    tree = Selector("主决策")

    # 1. 低血量逃跑
    flee = Sequence("低血逃跑")
    flee.add_child(Condition(lambda bb: bb["hp"] < 30, "血<30%"))
    flee.add_child(Action(lambda bb: move_to(bb, SAFE_POS), "撤退"))
    flee.add_child(Action(lambda bb: wait_and_heal(bb), "回血"))
    tree.add_child(flee)

    # 2. 背包满售卖
    sell = Sequence("背包满售卖")
    sell.add_child(Condition(lambda bb: len(bb["inv"]) >= 10, "背包满"))
    sell.add_child(Action(lambda bb: move_to(bb, SHOP_POS), "去商店"))
    sell.add_child(Action(lambda bb: sell_all(bb), "卖光"))
    tree.add_child(sell)

    # 3. 拾取
    loot = Sequence("拾取")
    loot.add_child(Condition(lambda bb: bb["drop"] is not None, "有掉落"))
    loot.add_child(Action(lambda bb: move_to(bb, bb["drop"]["pos"]), "走过去"))
    loot.add_child(Action(lambda bb: pick_up(bb), "拾取"))
    tree.add_child(loot)

    # 4. 战斗
    fight = Sequence("战斗")
    fight.add_child(Condition(lambda bb: bb["enemy"] is not None, "有敌人"))
    fight.add_child(Action(lambda bb: chase(bb), "追击"))
    fight.add_child(Action(lambda bb: attack(bb), "攻击"))
    tree.add_child(fight)

    # 5. 巡逻
    patrol = Action(lambda bb: wander(bb), "巡逻")
    tree.add_child(patrol)

    return tree

# 主循环
tree = make_tree()
bb = Blackboard(hp=100, inv=[], drop=None, enemy=None)
while running:
    bb.update(observe())        # 更新感知
    tree.tick(bb)               # 执行一次决策
    time.sleep(0.1)
```

## 五、RUNNING 与打断的正确用法

```
# 一个"走过去拾取"的动作可能跨多帧
def move_to(bb, target):
    if not at(bb["pos"], target):
        step_towards(bb["pos"], target)   # 走一步
        return Status.RUNNING              # 下帧继续
    return Status.SUCCESS
```

> 关键：**RUNNING 让长动作可暂停可续**。Selector 每帧都从最左边开始尝试，一旦"血低"条件满足，立刻打断"拾取/战斗"，这就是行为树的"应急优先级"。

## 五、冷却与装饰器

装饰器给节点套"壳"：

```python
class Cooldown(Node):   # 冷却：X 秒内只允许执行一次
    def __init__(self, child, seconds):
        super().__init__("cooldown")
        self.child = child
        self.last = 0
        self.cd = seconds

    def tick(self, bb):
        now = time.time()
        if now - self.last < self.cd:
            return Status.FAILURE
        s = self.child.tick(bb)
        if s != Status.RUNNING:
            self.last = now
        return s

class Inverter:          # 取反：把成功变失败
    def tick(self, bb):
        s = self.child.tick(bb)
        return Status.FAILURE if s == Status.SUCCESS else Status.SUCCESS
```

## 七、什么时候用行为树

```
✔ 任务多、有优先级、有打断（本系列后续都用它）
✔ 需要模块化复用（行为块到处插）
✔ 想可视化调试（py_trees 自带绘图）

✘ 单纯 3 个状态（状态机更快）
✘ 需要自己学习最优策略（用强化学习）
```

## 小结

- 行为树 = 选择器 + 序列 + 条件 + 动作 + 黑板
- RUNNING 支持长动作暂停续行，是打断的关键
- 用行为树重写打怪沙盒，优先级一目了然
- 遇到复杂任务，行为树优于状态机
