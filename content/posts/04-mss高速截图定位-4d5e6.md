# 屏幕读取：mss 高速截图与目标定位

> AI 代理的第一步是"看"，而"看"的带宽取决于**截图速度**。PIL 截图约 100ms，而 **mss** 可以把一张 800x600 的截图压到 10ms 以内。本文讲 mss 的正确打开方式，以及"只截游戏窗口"的高效技巧。

## 一、为什么用 mss

| 方式 | 单帧耗时（800x600） | 说明 |
|------|--------------------|------|
| pyautogui.screenshot | ~80-150ms | 慢，不适合实时 |
| mss | ~5-20ms | 快，C 底层实现 |
| 窗口 DC 截图 | ~5ms | 需 win32，稍复杂 |

> 游戏 AI 决策循环通常 10 FPS 就够，mss 绰绰有余。

## 二、mss 基础用法

```bash
pip install mss numpy
```

```python
import mss
import numpy as np

with mss.mss() as sct:
    # 1. 全屏截图
    monitor = sct.monitors[1]
    shot = sct.grab(monitor)
    img = np.array(shot)   # 转 numpy（BGRA）

    # 2. 只截指定区域（更快）
    region = {"left": 100, "top": 100, "width": 600, "height": 400}
    shot = sct.grab(region)
```

## 三、定位游戏窗口并只截窗口

```python
import win32gui
import mss

def get_window_region(title_part):
    """根据窗口标题找到窗口区域"""
    hwnd = win32gui.FindWindow(None, title_part)
    if not hwnd:
        return None
    left, top, right, bottom = win32gui.GetWindowRect(hwnd)
    return {
        "left": left, "top": top,
        "width": right - left, "height": bottom - top
    }
```

```python
with mss.mss() as sct:
    region = get_window_region("我的沙盒游戏")
    if region:
        img = np.array(sct.grab(region))
```

> 好处：只截游戏窗口，不截桌面，又快又准。

## 四、双缓冲：避免闪屏/撕裂

```
方案A（简单）：每帧重截 → 可能看到画面撕裂
方案B（推荐）：维护上一帧缓存，识别失败时重试
方案C：降低分辨率截图（先缩再识别）
```

```python
def grab_lowres(sct, region, scale=0.5):
    img = np.array(sct.grab(region))
    h, w = img.shape[:2]
    small = cv2.resize(img, (int(w * scale), int(h * scale)))
    return small
```

> 分辨率减半 → 速度翻倍，识别大目标完全够用。

## 五、图像与坐标换算

截图区域和游戏坐标可能有偏移（窗口边框、缩放），做一层换算：

```python
class ScreenMapper:
    def __init__(self, region):
        self.region = region

    def to_screen(self, img_x, img_y, scale=1.0):
        """图像坐标 → 屏幕坐标（用于点击）"""
        sx = self.region["left"] + int(img_x / scale)
        sy = self.region["top"] + int(img_y / scale)
        return sx, sy
```

```python
# 用法
sx, sy = mapper.to_screen(cx, cy)
pyautogui.click(sx, sy)
```

## 六、性能实战对比

```python
import time, mss

with mss.mss() as sct:
    t0 = time.perf_counter()
    for _ in range(50):
        sct.grab(sct.monitors[1])
    dt = time.perf_counter() - t0
    print(f"平均: {dt/50*1000:.1f} ms/帧")
```

> 实测 800x600 全屏 mss 约 8-15ms，足够支撑 10FPS 的 AI 循环。

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 截图全黑 | 检查游戏是否全屏独占模式（改窗口化） |
| 坐标偏移 | 统一用窗口区域坐标 + 映射 |
| 高 DPI 缩放 | Windows 设置 DPI 缩放 100% 或虚拟化 |
| 帧率不稳 | 降分辨率 / 只截局部 |

## 合规说明

> mss 只是"截图"，不碰游戏内存。但仍坚持：只用于开源/单机/自建游戏。

## 小结

- mss 是 Python 最快的截屏方案之一（~10ms）
- 只截游戏窗口（win32gui 定位）又快又干净
- 图像坐标 → 屏幕坐标需要一层映射
- 降分辨率是提速度的简单有效手段
- 截图是"眼睛"，配合 OpenCV 识别就是完整感知层
