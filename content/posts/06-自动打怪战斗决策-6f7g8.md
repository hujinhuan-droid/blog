# 自动打怪：行为识别与战斗决策

> 前面把"看"和"走"做好了，这一篇做**战斗大脑**：看到怪物怎么打？血少了怎么办？被包围怎么办？用状态机和行为树把"打怪逻辑"写得清晰可控。

## 一、战斗状态机

```
[巡逻/待机] ──看到敌人──> [接近敌人] ──进入攻击范围──> [攻击]
     ↑                                              │
     │                                              │ 敌人死亡
     │                                              ▼
     └────── 搜索下一目标 <─────── [拾取掉落] <──┐
                                              │ 无掉落
                                              └────┘
```

```python
class Fighter:
    def __init__(self):
        self.state = "IDLE"
        self.target = None

    def update(self, obs, actions):
        state = self.state
        if state == "IDLE":
            if obs["nearest_enemy"]:
                self.target = obs["nearest_enemy"]
                self.state = "APPROACH"
elif state == "APPROACH":
            d = dist(player, self.target)
            if d <= ATTACK_RANGE:
                self.state = "ATTACK"
            elif self.target is None:
                self.state = "IDLE"
        elif state == "ATTACK":
            actions.attack()
            if self.target["hp"] <= 0:
                self.state = "LOOT" if obs["has_drop"] else "IDLE"
            elif dist(self, self.target) > ATTACK_RANGE * 1.5:
                self.state = "APPROACH"
        elif state == "LOOT":
            actions.loot()
            self.state = "IDLE"
        return self.state
```

## 二、行为树：更清晰的战斗结构

行为树由节点组成：

```
[Selector: 选择策略]
├─ [Sequence: 生存优先]
│   ├─ [条件: HP < 20%] → [行为: 逃跑到安全区]
│   └─ [条件: 附近有药] → [行为: 拾取药]
├─ [Sequence: 战斗流程]
│   ├─ [条件: 有敌人] → [行为: 接近]
│   └─ [条件: 在范围] → [行为: 攻击]
└─ [Sequence: 收尾]
    ├─ [条件: 有掉落] → [行为: 拾取]
    └─ [行为: 待机]
```

```python
class Node:
    def tick(self, ctx): ...

class Condition(Node):
    def __init__(self, fn): self.fn = fn
    def tick(self, ctx):
        return "SUCCESS" if self.fn(ctx) else "FAIL"

class Action(Node):
    def __init__(self, fn): self.fn = fn
    def tick(self, ctx):
        self.fn(ctx)
        return "SUCCESS"

class Sequence(Node):
    def tick(self, ctx):
        for child in self.children:
            if child.tick(ctx) != "SUCCESS":
                return "FAIL"
        return "SUCCESS"
```

## 四、AI 代理的"战斗循环"（完整）

```python
def combat_loop(agent, vision, hands):
    while True:
        obs = vision.observe()          # 看
        action = agent.brain.decide(obs)  # 想
        hands.execute(action)           # 做
        # 战斗节奏控制
        if action == "ATTACK":
            time.sleep(0.3)             # 攻击间隔
        elif action == "MOVE":
            time.sleep(0.05)
        else:
            time.sleep(0.1)
```

## 四、行为识别（区分战斗/拾取/待机）

利用感知结果做"意图判断"：

```python
def recognize_intent(obs):
    if obs["hp"] < 0.2:        return "FLEE"
    if obs["enemy_in_range"]:  return "FIGHT"
    if obs["drop_nearby"]:     return "LOOT"
    return "WANDER"
```

> 关键：优先保命（逃跑）> 战斗 > 拾取 > 闲逛。

## 五、调参与边界

| 参数 | 说明 |
|------|------|
| ATTACK_RANGE | 攻击距离（格子/像素） |
| AGGRO_RANGE | 怪物察觉范围 |
| 攻击间隔 | 防过快点击 |
| 保命阈值 | HP 低于即撤离 |

> 建议把这些参数放 config.py，方便调。
