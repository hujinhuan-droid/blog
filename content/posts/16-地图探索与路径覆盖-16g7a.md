# 地图探索与路径覆盖：让 AI 自动逛遍整张地图

> 打怪拾荒最大的痛点：**地图哪里的怪多？哪里的宝箱没捡？** 手动规划路线太低效。本文实现三种探索策略——随机游走、网格覆盖、BFS 探测，让 AI 自动把整张地图"逛明白"。

## 一、探索策略对比

| 策略 | 原理 | 效率 | 简单度 |
|------|------|------|--------|
| 随机游走 | 随机选方向走 | 低（重复多） | ★ |
| 网格覆盖 | 按网格逐格访问 | 高（不重不漏） | ★★ |
| BFS 前沿 | 沿"未知边界"扩张 | 最高 | ★★★ |
| 重点采样 | 先去高价值区域 | 看需求 | ★★★ |

> 沙盒地图小，**网格覆盖**最好用；大图用 **BFS 前沿**更省。

## 二、网格覆盖：逐格清扫

把地图划分成网格，记录每格"已访问"，AI 按"最近未访问格"前进：

```python
class GridExplorer:
    def __init__(self, w, h, cell=40):
        self.grid = [[0] * (w // cell) for _ in range(h // cell)]
        self.cell = cell

    def mark_visited(self, x, y):
        gx, gy = x // self.cell, y // self.cell
        self.grid[gy][gx] = 1

    def nearest_unvisited(self, x, y):
        best, best_d = None, 1e9
        for gy, row in enumerate(self.grid):
            for gx, v in enumerate(row):
                if not v:
                    d = (gx * self.cell - x) ** 2 + (gy * self.cell - y) ** 2
                    if d < best_d:
                        best, best_d = (gx * self.cell, gy * self.cell), d
        return best
```

```python
explorer = GridExplorer(800, 600, cell=40)

def explore_step(bb):
    x, y = bb["pos"]
    explorer.mark_visited(x, y)
    target = explorer.nearest_unvisited(x, y)
    if target is None:
        return {"action": "done"}          # 全图逛完
    return {"action": "move", "target": target}
```

## 三、BFS 前沿探索

维护"已知区域"和"前沿（frontier）"——已知区域边缘的未知格，逐个去探索：

```python
from collections import deque

class FrontierExplorer:
    def __init__(self, map_w, map_h):
        self.known = [[False] * map_w for _ in range(map_h)]
        self.frontier = deque()

    def expand_from(self, x, y):
        # 把 (x,y) 四周未知格加入前沿
        for dx, dy in [(1,0),(-1,0),(0,1),(0,-1)]:
            nx, ny = x+dx, y+dy
            if not self.known[ny][nx]:
                self.frontier.append((nx, ny))

    def next_target(self, x, y):
        self.known[y][x] = True
        self.expand_from(x, y)
        # 弹出已知的前沿格，直到找到未知的
        while self.frontier:
            nx, ny = self.frontier.popleft()
            if not self.known[ny][nx]:
                return (nx, ny)
        return None
```

> BFS 前沿的好处：**永远往"没去过"的区域走**，不会走回头路，覆盖效率接近最优。

## 四、结合寻路：走到目标格

探索只负责"决定去哪"，真正走过去用上一批的 A*：

```python
from pathfinding import astar   # 复用第5篇的 A* 实现

def explore_with_path(bb):
    target = explorer.next_target(*bb["pos"])
    if target is None:
        return {"action": "done"}

    path = astar(bb["map"], bb["pos"], target)   # 返回路径点列表
    if path:
        return {"action": "move_along", "path": path}
    return {"action": "wait"}   # 被堵住，下帧再试
```

## 五、覆盖 + 打怪：边逛边打

探索策略要和战斗策略融合：

```
行为树顶层：
Selector
├── 有怪 → 打怪（战斗优先）
├── 背包满 → 回城卖（经济优先）
└── 没怪没满 → 探索下一个未访问格
```

```python
def explore_and_fight(bb):

        return sell_and_return(bb)    # 满了先卖
```

## 七、探索策略选择建议

```
小地图（<10x10 格）    → 网格覆盖最直观
大地图（有障碍/房间）  → BFS 前沿最优
地图有"高价值区域"    → 加权采样（价值高的先探）
有传送门/跳跃点        → 分层探索
```

## 小结

- 探索三件套：**网格覆盖 / BFS 前沿 / 寻路**
- 探索策略只管"去哪"，寻路管"怎么走"
- 战斗 > 经济 > 探索 的优先级用行为树组织
- 迷雾可视化是探索的调试利器
- AI 逛完整张地图 = 刷怪拾荒效率最大化
