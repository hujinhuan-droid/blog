# 多代理协作：让多个 AI 角色分工打副本

> 一个 AI 打怪太孤单。真实游戏里是团队作战：坦克拉怪、输出打伤害、奶妈加血、拾取捡宝。本文实现一个**多代理系统**，让多个 AI 角色在同一沙盒里分工协作，并解决"共享资源如何协调"这个核心问题。

## 一、多代理的三种协作模式

```
1. 主从模式（Master-Slave）
   一个主代理统一决策，其余只执行命令
   → 简单，但主代理是瓶颈

2. 黑板模式（Blackboard / 共享内存）
   所有代理读写同一块"公共状态"，各取所需
   → 灵活，需要防冲突

3. 消息模式（Message Passing）
   代理之间发消息：坦克喊"我拉住了！"、奶妈喊"我缺蓝！"
   → 最像真实团队，实现稍复杂
```

> 沙盒实战推荐 **黑板模式 + 消息模式混合**：状态共享用黑板，分工协作用消息。

## 二、代理基类

```python
class Agent:
    def __init__(self, name, role, brain):
        self.name = name
        self.role = role          # "tank" / "dps" / "healer" / "looter"
        self.brain = brain        # 行为树/状态机
        self.pos = (0, 0)
        self.hp = 100
        self.target = None

    def decide(self, bb):
        action = self.brain.tick(bb)   # 基于黑板做决策
        return action

    def act(self, action, world):
        # 执行动作（移动/攻击/拾取），更新世界
        ...
```

## 三、共享黑板（协调的核心）

```python
class WorldBlackboard:
    def __init__(self):
        self.monsters = []        # 所有怪物
        self.drops = []           # 所有掉落
        self.agents = {}          # 所有代理
        self.locks = {}           # 目标锁

    # 分配怪物：避免两个代理打同一只
    def claim_monster(self, agent, monster_id):
        if self.locks.get(monster_id) is None:
            self.locks[monster_id] = agent.name   # 抢占
            return True
        return False
```

## 四、分工：角色行为树

### 坦克（Tank）：拉怪 + 扛伤

```python
def tank_brain(bb):
    # 1. 血低了叫奶妈
    if bb.me.hp < 50:
        bb.send("healer", "need_heal", bb.me.pos)
    # 2. 冲进怪堆开嘲讽（引怪）
    nearest = bb.nearest_monster(bb.me.pos)
    if nearest:
        bb.claim_monster("me", nearest.id)
        return {"action": "attack", "target": nearest}
    return {"action": "wander"}
```

### 输出（DPS）

```python
def dps_brain(bb):
    # 1. 只打被坦克标记的怪（分工）
    locked = bb.monsters_locked_by_others()
    target = max(locked, key=lambda m: m.dps_priority, default=None)
    if target:
        return {"action": "attack", "target": target}
    # 2. 没活了就清小怪
    return {"action": "attack", "target": bb.nearest_monster(bb.me.pos)}
```

### 奶妈（Healer）

```python
def healer_brain(bb):
    # 1. 谁血低给谁加血（先坦克后自己）
    injured = sorted(bb.agents.values(), key=lambda a: a.hp)
    if injured and injured[0].hp < 60:
        return {"action": "heal", "target": injured[0]}
    # 2. 没人需要就拾取
    return {"action": "loot"}
```

### 拾荒者（Looter）

```python
def looter_brain(bb):
    # 只捡"没人认领"的掉落（避免抢）
    free_drops = [d for d in bb.drops if not bb.locks.get(d.id)]
    if free_drops:
        d = max(free_drops, key=lambda x: x.value)
        bb.locks[d.id] = "looter"
        return {"action": "loot", "target": d}
    # 背包满就回城卖
    if len(bb.me.inv) >= 10:
        return {"action": "sell"}
    return {"action": "wait"}
```

## 五、主循环：调度器

```python
world = WorldBoard()
agents = [Agent("坦克", "tank", tank_brain),
          Agent("输出", "dps", dps_brain),
          Agent("奶妈", "healer", healer_brain),
          Agent("拾荒", "looter", looter_brain)]

while running:
    # 1. 更新世界状态（怪物移动、掉落刷新）
    world.step()

    # 2. 每个代理感知 + 决策 + 执行
    for agent in agents:
        bb = world.get_blackboard(agent)   # 每个代理看到的视角
        action = agent.brain(bb)
        agent.act(action, world)

    # 3. 处理消息（奶妈收到求救）
    world.process_messages()

    render(world)
    time.sleep(0.1)
```

## 六、防冲突：两个代理抢同一颗药

```
问题：坦克和奶妈同时去捡同瓶药水 → 移动重叠

方案A：认领锁（claim）
  先到先得，谁先 claim 谁捡，后到的放弃
方案B：分权区域（zone）
  地图分区，每人负责一片，不越界
方案C：价值协商（auction）
  按角色优先级：奶妈 > 坦克 > 输出 > 拾荒
```

> 沙盒实战用 **认领锁 + 价值协商** 就够了，代码量小、行为符合直觉。
