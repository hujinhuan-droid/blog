# 模板匹配与特征检测：让 AI 认出技能图标和特殊掉落

> 上一批我们用颜色识别找"金色掉落物"，但真实游戏里：技能图标、装备、药水、宝箱长得千差万别。本文带你掌握**模板匹配（Template Matching）**和**特征检测（Feature Matching）**，让 AI 能认出"这张图标是什么"，还能在旋转/缩放下认出目标。

## 一、两种思路对比

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 模板匹配 | 小图在截图里滑窗比对 | 简单、快、无需训练 | 对旋转/缩放/光照敏感 |
| 特征检测 | 找关键点+描述子匹配 | 旋转缩放鲁棒 | 较慢、需要足够纹理 |

> 实用策略：**界面图标用模板匹配，游戏内实体用特征检测**。

## 二、模板匹配：认出技能图标

假设你截了一张技能栏的图 `skill_bar.png`，想找到"火球术"图标 `fireball.png` 在哪。

```python
import cv2
import numpy as np

scene = cv2.imread("skill_bar.png")     # 大图（技能栏）
tpl = cv2.imread("fireball.png")        # 模板（火球图标）

res = cv2.matchTemplate(scene, tpl, cv2.TM_CCOEFF_NORMED)
_, max_val, _, max_loc = cv2.minMaxLoc(res)

if max_val > 0.85:                      # 相似度阈值
    h, w = tpl.shape[:2]
    x, y = max_loc
    cv2.rectangle(scene, (x, y), (x + w, y + h), (0, 255, 0), 2)
    print(f"火球图标在: ({x}, {y})，相似度 {max_val:.2f}")
```

### 多目标：找所有匹配

```python
# 同一图标出现多次（多个技能槽）
threshold = 0.85
locations = np.where(res >= threshold)
for pt in zip(*locations[::-1]):       # (x, y) 列表
    cv2.rectangle(scene, pt, (pt[0] + w, pt[1] + h), (0, 0, 255), 1)
```

> 注意：matchTemplate 输出的每个像素代表"这个位置和模板的相似度"，需要设阈值+去重（NMS）。

## 三、多模板：一个图标池

游戏里技能很多，用"模板库"批量识别：

```python
TEMPLATES = {
    "fireball": cv2.imread("icons/fireball.png"),
    "frost":    cv2.imread("icons/frost.png"),
    "heal":     cv2.imread("icons/heal.png"),
}

def find_icons(scene, templates, thr=0.85):
    found = []
    for name, tpl in templates.items():
        res = cv2.matchTemplate(scene, tpl, cv2.TM_CCOEFF_NORMED)
        ys, xs = np.where(res >= thr)
        for x, y in zip(xs, ys):
            found.append((name, x, y, res[y, x]))
    return found
```

## 五、特征检测：认出旋转的怪物标志

颜色和模板都对"旋转/缩放"无能为力，用 **ORB 特征**（免费开源，无需专利）：

```python
import cv2

def match_features(img, ref, min_matches=10):
    orb = cv2.ORB_create(500)      # 500 个关键点
    kp1, des1 = orb.detectAndCompute(ref, None)
    kp2, des2 = orb.detectAndCompute(img, None)

    bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
    matches = bf.match(des1, des2)
    matches = sorted(matches, key=lambda m: m.distance)[:30]

    if len(matches) >= min_matches:
        # 计算单应性（可选，求目标位置）
        src = np.float32([kp1[m.queryIdx].pt for m in matches])
        dst = np.float32([kp2[m.trainIdx].pt for m in matches])
        H, _ = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
        return H, len(matches)
    return None, 0
```

> ORB 对旋转、缩放都有一定鲁棒性。适合"怪物背部图案""地图信标"这类纹理丰富的目标。

## 六、实战：识别特殊掉落（宝箱 vs 普通金币）

```python
BOX_TPL = cv2.imread("treasure_box.png")   # 宝箱模板
GOLD_TPL = cv2.imread("gold.png")          # 金币模板

def scan_drops(frame):
    drops = []
    for name, tpl in [("treasure", BOX_TPL), ("gold", GOLD_TPL)]:
        res = cv2.matchTemplate(frame, tpl, cv2.TM_CCOEFF_NORMED)
        ys, xs = np.where(res >= 0.8)
        for x, y in zip(xs, ys):
            drops.append({"type": name, "pos": (x, y),
                          "score": res[y, x]})
    return nms(drops)   # 去重
```

## 六、性能优化技巧

```
1. 缩小搜索区域：先找 HUD 区域，再在区域内匹配
2. 降低分辨率：匹配前 resize 到 1/2，速度 x4
3. 只对可能区域匹配：颜色粗筛 → 模板精确匹配
4. 缓存模板：模板图灰度化+初始化一次
5. 用灰度图匹配：速度比彩色快约 3 倍
```

```python
# 灰度加速示例
scene_g = cv2.cvtColor(scene, cv2.COLOR_BGR2GRAY)
```

## 七、什么时候用哪种

| 目标 | 方法 |
|------|------|
| UI 图标（固定大小） | 模板匹配 |
| 游戏内物品（会旋转） | ORB 特征 / 深度学习 |
| 会缩放/透视 | 特征检测 + Homography |
| 文字/数字（金币数） | OCR（pytesseract） |

## 小结

- 模板匹配：滑窗算相似度，适合固定图标
- NMS 去重：多框变一框
- ORB 特征：旋转缩放不变，适合实体识别
- 灰度+缩区域 = 提速关键
- 多方法组合：颜色粗筛 + 模板精配 + OCR 读数字
