# 自动化渗透测试：从脚本到编排平台

> 人工渗透慢且易遗漏，**自动化**是提升效率与覆盖度的关键。本文从 Bash/Python 脚本起步，讲到 nuclei、AutoRecon 等自动化框架与安全编排平台，教你构建自己的自动化渗透流水线。

## 一、为什么自动化

- 重复劳动：信息收集、扫描、爆破占 70% 时间
- 覆盖面：自动化可跑完整资产清单
- 稳定性：结果可复现、可审计
- 效率：100 个 IP 人工扫三天，脚本 10 分钟

## 二、脚本化：第一层自动化

### 资产收集脚本（Bash 示例）

```bash
#!/bin/bash
# 资产子域名批量收集
for domain in $(cat domains.txt); do
    subfinder -d $domain -silent >> subs.txt
    amass enum -passive -d $domain >> subs.txt
done
sort -u subs.txt | httpx -silent -status-code >> live.txt
```

### 端口扫描批量

```bash
# 批量 nmap
nmap -iL live.txt -sV -sC -oA scan_result
```

### Python 扩展

```python
import requests, sys

targets = open("urls.txt").read().splitlines()
for url in targets:
    try:
        r = requests.get(url, timeout=5)
        if r.status_code == 200:
            print(f"[+] {url} -> {r.headers.get('Server')}")
    except Exception:
        pass
```

## 三、nuclei：模板化漏洞扫描

```bash
# 安装
go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest

# 基础扫描
nuclei -u http://target.com

# 批量 + 模板过滤
nuclei -l urls.txt -t cves/ -t exposures/ -o results.txt

# 输出 JSON 便于集成
nuclei -l urls.txt -jsonl -o out.jsonl
```

## 四、自动化流水线（Pipeline）

### 经典渗透流水线

```
[资产发现] → [存活探测] → [端口/服务] → [漏洞扫描] → [利用尝试] → [报告]

subfinder → httpx → nmap → nuclei/sqlmap → metasploit → 生成报告
```

### 常用自动化框架

| 框架 | 说明 |
|------|------|
| AutoRecon | 一键信息收集+扫描（Kali 原生） |
| Prowler | 云安全自动化审计 |
| Nmap+msf | 传统组合 |
| Osmedeus | 多引擎扫描器 |
| Faraday | 渗透测试管理平台 |
| Dradis | 报告协作平台 |
| Metasploit | 自动化利用模块 |

## 四、编排平台：企业级自动化

### SOAR / 编排平台

```
- 统一入口（工单/接口）
- 编排剧本（Playbook）：攻击→处置→报告
- 与 SIEM/EDR 联动
- 定时自动巡检
```

## 五、AI 辅助渗透测试

- AI 自动生成 Payload、参数调整
- 自动分析扫描结果（去误报）
- 自动生成报告（证据 + 建议）

> 说明：AI 自动化只能辅助，核心逻辑与授权仍需人工把关。

## 六、自动化与合规

- 自动化扫描**必须限定在授权范围**（容易扫过头）
- 大范围扫描= 高风险，需通知客户
- 报告要含扫描时间、目标、结果

## 安全合规

> 自动化工具是把双刃剑。未经授权的批量扫描属于违法行为，务必在授权书范围内使用。

## 小结

- 自动化第一步：脚本（Bash/Python）
- 标准流程：subfinder + httpx + nuclei 三件套
- 漏洞扫描：nuclei（模板化、可批量）
- 平台化：orcon、Faraday、企业编排平台
- 授权永远优先，自动化不例外
