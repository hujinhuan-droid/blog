## 二、配置中心：一行改全局

```python
import yaml

class Config:
    def __init__(self, path="config.yaml"):
        with open(path, encoding="utf-8") as f:
            self.cfg = yaml.safe_load(f)

    def get(self, key, default=None):
        return self.cfg.get(key, default)

# config.yaml 示例
# vision:
#   template_threshold: 0.85
#   use_cnn: true
# brain:
#   hp_flee_threshold: 30
#   sell_inv_ratio: 0.8
# pipeline:
#   threads: 4
#   queue_size: 3
```

> 生产级的关键：**所有参数进配置**，改阈值不用改代码。

## 三、主程序：按需组装

```python
class ProductionAgent:
    def __init__(self, config):
        self.cfg = Config(config)
        # 按配置组装各模块
        self.vision = VisionPipeline(self.cfg)   # 视觉（可线程化）
        self.brain = BehaviorBrain(self.cfg)     # 决策（行为树）
        self.economy = EconomyManager(self.cfg)   # 经济
        self.hands = Hands(self.cfg)              # 操作

    def run(self):
        # 启动流水线线程
        self.vision.start_threads()
        while self.running:
            obs = self.vision.latest()           # 取最新画面结果
            action = self.brain.decide(obs)     # 行为树决策
            if action["type"] == "sell":
                self.economy.do_sell(action)
            else:
                self.hands.execute(action)
            time.sleep(self.cfg.get("loop_delay", 0.05))

    def shutdown(self):
        self.vision.stop_threads()   # 安全退出线程
```

## 四、模块间接口约定

```
vision 输出（给 brain 的"观察"）：
  {
    "pos": (x, y), "hp": 80,
    "enemy": {"pos":(..), "hp":20} | None,
    "drops": [{"type":"potion","pos":(..), "value":15}, ...],
    "inv": ["potion", "weapon"...],
    "shop_dist": 120
  }

brain 输出（给 hands 的"动作"）：
  {"type": "move|attack|loot|sell|wait",
   "target": (x,y) or item, "params": {...}}
```

> 接口固定后，**换视觉算法、换决策算法都不影响其他层**——这就是模块化红利。

## 五、从"能跑"到"生产级"的检查清单

```
□ 配置全部外置（config.yaml），不硬编码
□ 视觉/决策/操作解耦，可单独替换
□ 线程安全退出（stop 事件）
□ 关键指标日志（收益/胜率/延迟）
□ 错误处理：识别失败、窗口丢失有兜底
□ 性能达标：延迟 < 100ms/帧
□ 合规自查：只跑开源/自建游戏
```
