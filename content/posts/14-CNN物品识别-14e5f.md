# CNN 物品识别：用 PyTorch 训练自己的掉落物分类器

> 模板匹配怕光照、怕旋转、怕换皮肤。要真正"认出"五花八门的掉落物（药水/武器/防具/宝箱/金币），需要让 AI 自己学习特征——这就是 **CNN 图像分类**。本文用 PyTorch 训练一个小型 CNN，让 AI 识别游戏掉落物的类型，并集成进代理。

## 一、整体流程

```
1. 从沙盒游戏截图，人工打标签
2. 用 PyTorch 训练 CNN 分类器
3. 导出模型，集成到 agent 的 vision 层
4. 实时推理：截掉落物区域 → 分类 → 决策
```

## 二、造数据集：从 Pygame 截图 + 自动标注

先让沙盒输出"带标签的掉落物图片"：

```python
import pygame, cv2, os

def export_dataset(game, out_dir="dataset", n=1000):
    os.makedirs(out_dir, exist_ok=True)
    for i in range(n):
        game.spawn_random_drop()              # 随机生成掉落
        surf = game.screen.subsurface(game.drop_rect())   # 截取掉落物区域
        arr = pygame.surfarray.array3d(surf)
        img = cv2.cvtColor(arr, cv2.COLOR_RGB2BGR)
        # 按掉落类型存入不同文件夹（即标签）
        label = game.drop_type()
        cv2.imwrite(f"{out_dir}/{label}/{i:04d}.png", img)
```

> 关键技巧：**直接在游戏里读内部对象生成数据集**，又快又准，这就是自建沙盒的优势。

## 三、定义 CNN 模型

一个够用的小模型（4 个卷积层）：

```python
import torch
import torch.nn as nn

class DropCNN(nn.Module):
    def __init__(self, num_classes=5):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 32x32→16x16
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # →8x8
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # →4x4
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(),                  # →4x4
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128 * 4 * 4, 128),
            nn.ReLU(),
            nn.Linear(128, num_classes)
        )

    def forward(self, x):
        return self.classifier(self.features(x))
```

## 三、训练循环

```python
from torch.utils.data import DataLoader, ImageFolder
from torchvision import transforms

transform = transforms.Compose([
    transforms.Resize((32, 32)),
    transforms.RandomRotation(15),      # 数据增强：旋转
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize([0.5]*3, [0.5]*3)
])

dataset = ImageFolder("data", transform=transform)
loader = DataLoader(dataset, batch_size=32, shuffle=True)

model = DropCNN(num_classes=len(dataset.classes))
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(20):
    for imgs, labels in loader:
        pred = model(imgs)
        loss = loss_fn(pred, labels)
        opt.zero_grad(); loss.backward(); opt.step()
    print(f"epoch {epoch}: loss {loss.item():.3f}")
```

## 四、测试与评估

```python
model.eval()
correct = total = 0
with torch.no_grad():
    for imgs, labels in loader:
        pred = model(imgs).argmax(dim=1)
        correct += (pred == labels).sum().item()
        total += labels.size(0)
print(f"准确率: {correct / total:.2%}")
```

> 自建沙盒数据简单，通常 10-20 轮就能到 95%+。数据增强（旋转/翻转）能显著提升泛化。

## 五、导出并集成到代理

```python
torch.save(model.state_dict(), "drop_cnn.pth")

# === vision.py 集成 ===
class CNNVision:
    def __init__(self):
        self.model = DropCNN(num_classes=5)
        self.model.load_state_dict(torch.load("drop_cnn.pth"))
        self.model.eval()
        self.classes = ["gold", "potion", "weapon", "armor", "jewelry"]

    def classify(self, img):
        """img: 32x32 BGR 掉落物图片"""
        t = transforms.ToTensor()(cv2.cvtColor(img, cv2.COLOR_BGR2RGB))
        with torch.no_grad():
            prob = self.model(t.unsqueeze(0)).softmax(dim=1)
        idx = prob.argmax().item()
        return self.classes[idx], prob.max().item()
```

## 六、CPU 推理优化

```
1. 模型小（<1MB），CPU 推理 <5ms，完全够
2. 只对"候选框"分类，不做全图扫描
3. 批处理：把一帧所有掉落物一次分类
4. 半精度（fp16）可进一步加速（需硬件支持）
```

```python
# 批量分类一帧中的所有掉落物
def classify_all(self, crops):   # crops: 列表[img]
    ts = torch.stack([self._to_tensor(c) for c in crops])
    with torch.no_grad():
        preds = self.model(ts).argmax(dim=1)
    return [self.classes[p] for p in preds.tolist()]
```

## 七、什么时候用 CNN 而不是模板

```
✔ 物品种类多、外观变化大（换皮肤/旋转/光照）
✔ 需要"泛化"：新物品和训练过的类似就能认
✔ 掉落物多，批量分类效率高

✘ 就 3~5 个固定图标（模板匹配更简单）
✘ 没有训练数据（先做数据集）
✘ 实时性要求极高（模板匹配更快）
```
