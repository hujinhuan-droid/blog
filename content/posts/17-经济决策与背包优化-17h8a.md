# 经济决策与背包优化：让 AI 知道什么该捡、什么该卖

> 背包只有 10 格，满地都是金币、药水、装备、垃圾。**捡什么、扔什么、卖什么、留什么** 直接决定收益。本文给代理装上"经济学大脑"：物品估值、背包价值最大化、自动售卖策略。

## 一、物品估值：一切决策的基础

给每个物品一个"价值分"，综合考虑售价、用途、稀有度：

```python
class Item:
    def __init__(self, name, sell_price, category,
                 rarity="common", weight=1):
        self.name = name
        self.sell_price = sell_price
        self.category = category   # weapon/armor/potion/junk
        self.rarity = rarity       # common/rare/epic/legendary
        self.weight = weight       # 占背包格数

    def value_score(self, need_potion=False):
        """综合价值分：售价 + 实用 + 稀有度加成"""
        score = self.sell_price
        if self.category == "potion" and need_potion:
            score += 30            # 需要时药水很值
        rarity_bonus = {"common": 0, "rare": 5,
                        "epic": 15, "legendary": 50}
        score += rarity_bonus[self.rarity]
        return score / self.weight  # 每格价值（性价比）
```

## 二、背包价值评估

```python
class Backpack:
    def __init__(self, capacity=10):
        self.capacity = capacity
        self.items = []

    @property
    def is_full(self):
        return len(self.items) >= self.capacity

    @property
    def total_value(self):
        return sum(i.sell_price for i in self.items)

    def value_per_slot(self):
        return self.total_value / max(1, len(self.items))
```

> 核心指标：**每格价值（value_per_slot）**。回城售卖的收益 = 背包总价值 - 来回时间成本。背包里垃圾越多，越该早卖。

## 三、捡取决策：这个掉落值不值得捡

```python
class PickupPolicy:
    def __init__(self, backpack, shop_dist=100):
        self.backpack = backpack
        self.shop_dist = shop_dist

    def should_pick(self, item, current_value_per_slot):
        """值不值得捡？"""
        # 1. 背包没满 → 先看是否比最差的强
        if not self.backpack.is_full:
            return item.value_score() >= 0

        # 2. 背包满了 → 只捡比最差物品更值钱的
        worst = min(self.backpack.items,
                    key=lambda i: i.value_score())
        if item.value_score() > worst.value_score():
            # 扔掉最差的，捡新的（替换）
            self.backpack.items.remove(worst)
            self.backpack.items.append(item)
            return True
        return False
```

## 四、售卖决策：什么时候回城

```python
def should_sell(backpack, shop_dist, farm_efficiency):
    """
    farm_efficiency: 每秒能赚多少钱（拾荒收益）
    回城收益 = 背包总价值
    回城成本 = 来回时间 × 拾荒效率
    """
    profit = backpack.total_value
    cost = 2 * shop_dist / MOVE_SPEED * farm_efficiency
    return profit > cost   # 卖货收益 > 路上损失才回去
```

> 黄金法则：**不是"满了就卖"，而是"卖完再回来赚得比路上亏的多"才卖**。

## 五、售卖时的分类决策

```python
def sell_decision(items):
    """返回 (卖掉的列表, 留下的列表)"""
    sell, keep = [], []
    for item in items:
        if item.category == "potion" and item.rarity != "common":
            keep.append(item)       # 稀有药水留着用
        elif item.category == "weapon" and item.rarity == "legendary":
            keep.append(item)      # 传说武器留着
        else:
            sell.append(item)      # 其余全卖
    return sell, keep
```

## 六、完整经济决策示例

```python
def economic_brain(bb):
    bp = bb["backpack"]
    # 1. 有掉落物
    if bb["nearby_drop"]:
        item = bb["nearby_drop"]
        if PickPolicy(bp).should_pick(item, bp.value_per_slot()):
            return {"action": "pick", "target": item}
        return {"action": "ignore"}

    # 2. 背包满了且该卖
    if bp.is_full and should_sell(bp, bb["shop_dist"], bb["farm_rate"]):
        sell, keep = sell_pack(bp.items)
        bp.items = keep
        return {"action": "go_sell", "items": sell}

    # 3. 背包快满了但还没到回城时机 → 继续打
    return {"action": "keep_farming"}
```

## 小结

- 估值 → 决策 → 售卖，三层经济大脑
- 捡不捡 = 价值分比较；卖不卖 = 收益 vs 路费
- 传说/药水留，普通全卖
- 核心指标：背包每格价值、回城时机
