# 自动寻路：A* 与 BFS 在地图上的路径规划

> AI 代理要"自动跑向怪物、自动跑向掉落物、自动回城"，全靠**寻路算法**。本文讲清 BFS 与 A* 的原理和 Python 实现，让代理从"原地傻站"变成"自己走到目标"。

## 一、为什么需要寻路

直接直线走向目标会撞墙、绕路。寻路算法在有障碍的地图上找最短路径。

```
地图（# 是障碍，S 起点，G 终点）
##########
S....#...#
#....#...#
#....####.#
#....#..G#
##########
```

## 二、BFS：广度优先搜索（保证最短路径）

```python
from collections import deque

def bfs(grid, start, goal):
    """grid: 0可走 1障碍; 返回路径坐标列表"""
    rows, cols = len(grid), len(grid[0])
    q = deque([start])
    visited = {start}
    parent = {start: None}
    dirs = [(0,1),(0,-1),(1,0),(-1,0)]

    while q:
        cur = q.popleft()
        if cur == goal:
            break
        for dx, dy in dirs:
            nx, ny = cur[0]+dx, cur[1]+dy
            nxt = (nx, ny)
            if (0 <= nx < rows and 0 <= ny < cols
                and grid[nx][ny] == 0 and nxt not in visited):
                visited.add(nxt)
                parent[nxt] = cur
                q.append(nxt)

    # 回溯路径
    if goal not in parent:
        return None
    path = []
    step = goal
    while step is not None:
        path.append(step)
        step = parent[step]
    return path[::-1]
```

> BFS 保证最短路径，但会盲目扩展所有方向。

## 三、A* 算法：启发式寻路

A* 用**估价函数** f = g + h 引导搜索：

- g：从起点到当前点的实际代价
- h：当前点到终点的估计代价（曼哈顿距离）

```python
import heapq

def a_star(grid, start, goal):
    rows, cols = len(grid), len(grid[0])

    def h(p):   # 曼哈顿距离
        return abs(p[0]-goal[0]) + abs(p[1]-goal[1])

    open_heap = []          # (f, g, 点)
    heapq.heappush(open_heap, (h(start), 0, start))
    g_score = {start: 0}
    parent = {start: None}
    dirs = [(0,1),(0,-1),(1,0),(-1,0)]

    while open_heap:
        f, g, cur = heapq.heappop(open_heap)
        if cur == goal:
            break
        for dx, dy in dirs:
            nx, ny = cur[0]+dx, cur[1]+dy
            nxt = (nx, ny)
            if not (0 <= nx < rows and 0 <= ny < cols) or grid[nx][ny] == 1:
                continue
            ng = g + 1
            if ng < g_score.get(nxt, float("inf")):
                g_score[nxt] = ng
                parent[nxt] = cur
                heapq.heappush(open_heap, (ng + h(nxt), ng, nxt))

    if goal not in parent:
        return None
    path = []
    step = goal
    while step is not None:
        path.append(step)
        step = parent[step]
    return path[::-1]
```

## 四、在 Pygame 沙盒里落地

把寻路接到沙盒：

```python
def grid_to_path(grid, start, goal):
    path = a_star(grid, start, goal)
    return path

def move_along_path(player, path, speed=4):
    if not path:
        return
    tx, ty = path[0]
    dx, dy = tx - player.x, ty - player.y
    dist = (dx**2 + dy**2) ** 0.5
    if dist < speed:
        player.x, player.y = tx, ty
        path.pop(0)
    else:
        player.x += dx / dist * speed
        player.y += dy / dist * speed
```

```python
# 主循环中：目标 = 最近的金币掉落
target = nearest_drop(player, gold_list)
path = a_star(world_map, (py, px), target)

```

> 每帧重算 path 或者按步走都行；地图小时每帧重算也没问题。

## 五、寻路优化技巧

| 技巧 | 说明 |
|------|------|
| 每帧不重算 | 只有到达新格/目标变化才重算 |
| 网格细分 | 大格(20px) → 小格(4px) 分级 |
| 缓存路径 | 同一目标复用 |
| 多目标选择 | 先选最近目标再寻路 |

## 七、合规小结

- 寻路是**纯算法**，在自建/开源游戏中完全合法
- BFS 保证最短；A* 更快（启发式）
- 网格越小越精确，也越慢，要平衡
- 落地时：坐标 → 网格 → 寻路 → 逐格移动
