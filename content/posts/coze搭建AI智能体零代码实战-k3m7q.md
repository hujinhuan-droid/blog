# 用 Coze 搭建你的第一个 AI 智能体：零代码实战指南

不会写代码，也能搭一个「能查资料、能画图、能发邮件」的 AI 助手吗？答案是：能。Coze（扣子）是目前门槛最低的智能体搭建平台之一，全程拖拽配置，10 分钟出活。

## 什么是 Coze

Coze 是字节跳动推出的 AI 智能体开发平台。你不需要写一行代码，只需要：

- 选一个大模型当"大脑"
- 配几个"插件"当"手脚"（搜索、画图、代码运行等）
- 写一段"人设"告诉它怎么干活

把它想象成"拼乐高"：模型是核心模块，插件是功能积木，提示词是说明书。

## 实战：搭一个"AI 行业分析师"

我们做一个能自动搜集行业信息、整理摘要、生成分析报告的智能体。

### 第 1 步：创建 Bot

1. 打开 [coze.cn](https://www.coze.cn)，登录后点击「创建 Bot」
2. 填写名称：「行业分析助手」
3. 选择模型：GPT-4o 或 Doubao-Pro（免费额度够测试）

### 第 2 步：写人设 Prompt

在「人设与回复逻辑」里粘贴以下内容：

```
你是一个专业的行业分析师。
用户会给你一个行业名称，你需要：
1. 用搜索插件查找该行业的最新动态和关键数据
2. 总结行业现状（3-5 条核心观点）
3. 列出该行业的 Top 5 代表企业
4. 给出未来 1 年的 3 个趋势预测
输出格式：Markdown，带标题层级
```

### 第 3 步：添加插件

点击「插件」→「添加插件」，搜索并添加：

| 插件名 | 作用 |
|--------|------|
| Google 搜索 | 实时搜索行业新闻 |
| LinkReader | 读取搜索结果网页内容 |
| Code Runner | 处理数据计算 |

### 第 4 步：测试

在右侧预览区输入：「新能源汽车行业」，观察它是否自动调用搜索、读取网页、生成报告。

### 第 5 步：发布

点击右上角「发布」，选择渠道：
- **Bot Store**：在 Coze 商店公开
- **飞书**：嵌入飞书机器人
- **API**：获取接口地址，集成到自己的应用

## 实用技巧

**1. 用工作流实现多步任务**

如果单轮对话搞不定复杂任务，用「工作流」编排：
```
搜索 → 网页读取 → 数据提取 → 摘要生成 → 格式化输出
```
每个节点选一个插件，像画流程图一样串起来。

**2. 用知识库让 Bot 读懂私有数据**

点击「知识库」→ 上传 PDF/Word/网页链接。Bot 回答时会优先从你的资料中找答案，而不是凭空编。

**3. 用变量让对话更灵活**

在开场白里设置变量 `{{行业名称}}`，用户填入后直接触发分析流程，省去来回提问。

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| Bot 不调用插件 | 在 Prompt 中明确写"请使用搜索插件查找" |
| 回答太长 | 在 Prompt 里限制字数或条数 |
| 搜索结果不准 | 增加搜索关键词约束，如 `site:gov.cn` |
| 多轮对话丢失上下文 | 开启「长期记忆」功能 |
