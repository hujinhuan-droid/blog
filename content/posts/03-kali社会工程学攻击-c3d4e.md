# 社会工程学攻击：人，才是安全链中最薄弱的一环

> 网络安全界有句名言："最安全的系统，往往被一个不小心点了链接的员工击穿。"社会工程学（Social Engineering）正是利用"人"的弱点而非系统漏洞来获取敏感信息或权限的攻击方式。据 Verizon 报告，约 70% 的安全事件都涉及某种形式的社会工程学。

## 一、社会工程学是什么

社会工程学是通过**心理操纵**而非技术手段，诱使目标执行特定动作或泄露敏感信息。

### 常见攻击形式

| 形式 | 说明 | 示例 |
|------|------|------|
| 钓鱼邮件 | 伪造发件人/诱饵链接 | "您的账户异常，点击验证" |
| 鱼叉钓鱼 | 针对特定个人定制 | 伪装成老板发邮件索要转账 |
| 电话诈骗（Vishing） | 语音通话欺诈 | 伪装成客服索取验证码 |
| 短信钓鱼（Smishing） | 短信链接 | 伪基站短信 |
| 水坑攻击 | 攻击目标常访问的网站 | 植入恶意脚本 |
| 尾随（Tailgating） | 物理混入 | 假装员工尾随进入办公室 |

### 攻击链

```
信息收集（了解目标） → 建立信任（伪装身份） → 诱导行动（点击/泄露/转账）
```

## 二、SET：Kali 内置的社会工程学工具包

Kali 自带 **SET（Social Engineering Toolkit）**，可以快速生成钓鱼页面、载荷和邮件模板。

```bash
# 启动 SET
sudo setoolkit

# 主菜单
1) 社会工程学攻击
2) 快速渗透测试
3) 第三方模块
4) 更新 SET
```

### 1. 创建钓鱼网站（Credential Harvester）

```
选择 1（Social Engineering）→ 2（Website Attack Vectors）
→ 3（Credential Harvester Attack Method）
→ 2（Site Cloner）
→ 输入克隆的 URL（如登录页）
→ SET 会在本地起一个与目标几乎一模一样的登录页
→ 目标输入账密时，被记录
```

> 钓鱼页面通常会诱导用户输入真实账号密码。防御端应识别域名、校验 HTTPS 证书。

### 2. 创建钓鱼邮件

```
选择 1 → 1（Spear-Phishing Attack Vectors）
→ 选择一个攻击载荷（如恶意附件）
→ 或选纯钓鱼邮件
→ 填入目标邮箱、邮件标题、内容
```

### 3. 创建恶意 USB / 感染介质

```
SET 支持生成 "自启动" 的恶意工具，如 U 盘插入后自动执行。
```

## 三、实战：搭建一个钓鱼场景

### 场景：伪造公司 IT 邮件

```
目标：财务部小王
目的：骗取公司 VPN 账号密码

1. 用 SET 克隆公司 VPN 登录页
2. 伪造邮件：发件人伪装成 IT 部门，主题「VPN 密码即将到期」
3. 邮件正文：引导点击链接 → 跳转到克隆页面
4. 小王输入账号密码 → 被后台记录
5. 用拿到的 VPN 凭证接入内网 → 横向移动
```

### 关键手法

- **域名相似**：`vpn-company.com` vs `company.com`，视觉不可分辨
- **邮箱伪造**：显示名伪造为 `IT Support <it@company.com>`，但真实发件地址是外部域
- **紧迫感**："立即处理，否则账户冻结" 降低思考
- **HTTPS 欺骗**：用免费证书做克隆页 HTTPS，看起来正规

## 四、防御社会工程学

### 个人层面

- 不点击陌生链接 / 附件
- 校验发件人真实地址（而非显示名）
- 敏感信息绝不通过邮件/电话提供
- 开启多因素认证（MFA）

### 组织层面

| 措施 | 说明 |
|------|------|
| 安全意识培训 | 定期演练钓鱼测试 |
| 邮件网关 | 拦截外部仿冒域名 |
| DMARC/DKIM/SPF | 邮件伪造防护 |
| 零信任 | 默认不可信，持续验证 |
| 事件响应 | 快速识别与处置 |

## 五、实操演练环境

- **GoPhish**：开源钓鱼测试平台，适合企业内部钓鱼演练
- **SET**：Kali 自带，用于教育
- **Social-Phish**：一键钓鱼页

```bash
# 安装 GoPhish（在 Kali 或其他 Linux）
git clone https://github.com/gophish/gophish
cd gophish
./gophish  # 默认 :3333 管理后台，:80 钓鱼服务
```

## 六、法律与合规红线

> 社会工程学本质是**欺骗**，是违法行为吗？**未经授权**收集他人信息、骗取账号、仿冒身份进行测试，均违反《网络安全法》《个人信息保护法》《刑法》相关规定。**仅有授权**的内部红队/渗透测试中，才能进行钓鱼演练。切勿对第三方真实企业/个人实施。

## 小结

- 社会工程学攻击目标是人，不是系统
- SET 可以一键搭建钓鱼页面 / 邮件 / 恶意 USB
- 防钓鱼核心：人（培训）+ 技术（DMARC、MFA、邮件网关）
- 钓鱼演练要合法合规，授权进行
