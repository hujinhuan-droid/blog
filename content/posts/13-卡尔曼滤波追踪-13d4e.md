# 移动目标追踪：用卡尔曼滤波跟踪移动的怪物

> 怪物会跑、会闪、会消失。如果 AI 每帧都重新识别，目标稍微移动就点空；截图偶尔漏一帧，目标就"消失"。本文教你用**卡尔曼滤波（Kalman Filter）**预测怪物位置，让 AI 在目标被遮挡或漏检时依然能"追着打"。

## 一、为什么需要预测

```
直接跟踪的问题：
  帧1 识别到怪物 @ (100,100)
  帧2 怪物跑了，识别在 (120,100)  → 点击 (120,100)
  帧3 怪物跑了，漏检！            → 不知道点哪  ✗

卡尔曼跟踪：
  帧1 识别到怪物 @ (100,100)，估计速度 (20,0)
  帧2 漏检 → 预测位置 (120,100)    → 还能继续追  ✓
  帧3 识别到 (140,100) → 修正估计 → 更准        ✓
```

> 核心思想：**不只看当前帧，还结合"上一帧+运动模型"做预测**，识别有噪声、有漏检也能稳定跟踪。

## 二、卡尔曼滤波直觉理解

卡尔曼滤波是两个信息源的加权融合：

```
预测（物理模型）：上帧位置 + 速度 × 时间 → 预测位置
观测（视觉识别）：识别算法给出的位置（有噪声）

最优估计 = 预测 + 增益 × (观测 - 预测)
         ↑                    ↑
    越准越信它         "新息"，乘以卡尔曼增益 K
```

- 观测噪声大 → K 小 → 更信预测
- 观测噪声小 → K 大 → 更信观测

## 三、用 OpenCV 的卡尔曼滤波器

OpenCV 内置 `cv2.KalmanFilter`，直接用：

```python
import cv2
import numpy as np

class TargetTracker:
    def __init__(self):
        # 状态: [x, y, vx, vy]   观测: [x, y]
        self.kf = cv2.KalmanFilter(4, 2)

        # 状态转移矩阵 A：x' = x + vx*dt, vx' = vx
        self.kf.transitionMatrix = np.array([
            [1, 0, 1, 0],
            [0, 1, 0, 1],
            [0, 0, 1, 0],
            [0, 0, 0, 1]
        ], dtype=np.float32)

        # 观测矩阵 H：只看位置
        self.kf.measurementMatrix = np.array([
            [1, 0, 0, 0],
            [0, 1, 0, 0]
        ], dtype=np.float32)

        # 过程噪声（模型不准的程度）和观测噪声（识别噪声）
        self.kf.processNoiseCov = np.eye(4, dtype=np.float32) * 0.03
        self.kf.measurementNoiseCov = np.eye(2, dtype=np.float32) * 1.0

        self.initialized = False

    def init(self, x, y):
        self.kf.statePre = np.array([[x], [y], [0], [0]], np.float32)
        self.kf.statePost = self.kf.statePre.copy()
        self.initialized = True

    def update(self, detected_pos=None):
        """每帧调用：有检测传坐标，无检测传 None"""
        if detected_pos is not None and not self.initialized:
            self.init(*detected_pos)
            return detected_pos

        # 1. 预测
        pred = self.kf.predict()

        # 2. 有观测则修正
        if detected_pos is not None:
            meas = np.array([[detected_pos[0]], [detected_pos[1]]], np.float32)
            corrected = self.kf.correct(meas)
            return (float(corrected[0]), float(corrected[1]))

        return (float(pred[0]), float(pred[1]))   # 漏检，用预测
```

## 四、集成到打怪代理

```python
tracker = TargetTracker()

def track_enemy(frame):
    # 1. 颜色/模板识别怪物（返回位置或 None）
    detected = find_enemy(frame)          # 复用第3/12篇的识别

    # 2. 卡尔曼修正/预测
    pos = tracker.update(detected)

    # 3. 点击追击
    if pos:
        pyautogui.click(pos[0], pos[1])
    return pos
```

### 参数调优经验

```
processNoiseCov 大 → 更信观测（目标加速猛）
measurementNoiseCov 大 → 更信预测（识别噪声大）
实战建议：
  识别不稳定（图标闪） → 把测量噪声调大
  目标速度快/变速   → 把过程噪声调大
```

## 五、多目标：用多个跟踪器

一帧可能有多只怪物，用"匹配+分配"维护多个跟踪器：

```python
class MultiTracker:
    def __init__(self, max_age=10):
        self.trackers = {}   # id -> (Kalman, age)
        self.next_id = 0
        self.max_age = max_age

    def update(self, detections):
        # 简化版：最近邻匹配
        used = set()
        for det in detections:
            best_id, best_d = None, 1e9
            for tid, (kf, _) in self.trackers.items():
                if tid in used: continue
                pred = kf.predict()
                d = dist(det, (pred[0], pred[1]))
                if d < best_d:
                    best_id, best_d = tid, d
            if best_id is not None and best_d < 30:   # 距离阈值
                kf, _ = self.trackers[best_id]
                meas = np.array([[det[0]], [det[1]]], np.float32)
                kf.correct(meas); used.add(best_id)
            else:
                tid = self.max_id()
                self.trackers[tid] = (make_kf(), 0)
                self.trackers[tid][0].init(*det); used.add(tid)

        # 清理超龄跟踪器
        self.trackers = {tid: (kf, age+1)
                         for tid, (kf, age) in self.trackers.items()
                         if tid in used or age < self.max_age}
```

> 简单说：**新检测先找最近的旧轨迹，太远就开新轨迹，太久没更新就删除**——这就是多目标追踪（多目标 SORT 的简化版）。

## 六、追踪效果可视化

```python
def draw_track(frame, trackers):
    for tid, (kf, _) in trackers.trackers.items():
        pred = kf.predict()
        x, y = int(pred[0]), int(pred[1])
        cv2.circle(frame, (x, y), 8, (0, 255, 0), 2)
        cv2.putText(frame, f"ID{tid}", (x+10, y),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 1)
    return frame
```

## 七、局限与进阶

```
卡尔曼：假设线性运动 + 高斯噪声（够用，快）
扩展卡尔曼(EKF)：目标转弯（非线性），精度更高
粒子滤波：复杂遮挡场景（更慢更准）
DeepSORT：外观特征 + 运动模型（真实视觉追踪标准）
```

> 沙盒打怪场景，卡尔曼已经绰绰有余。

## 小结

- 卡尔曼 = 预测 + 修正，漏检也能追
- 状态 [x, y, vx, vy]，观测位置即可
- 过程/测量噪声是核心调参旋钮
- 多目标用"最近邻匹配 + 超龄清理"
- 视觉追踪是打怪代理的"稳准"关键
