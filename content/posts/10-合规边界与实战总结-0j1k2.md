## 二、agent.py 主循环（把一切串起来）

```python
import time
from vision import Vision
from brain import Brain
from hands import Hands
from path import AStar

class GameAgent:
    def __init__(self):
        self.vision = Vision()
        self.brain = Brain()
        self.hands = Hands()
        self.path = AStar()

    def run(self, fps=10):
        while True:
            obs = self.vision.observe()       # 1. 看
            action = self.brain.decide(obs)   # 2. 想
            self.hands.execute(action)        # 3. 做
            time.sleep(1 / fps)

if __name__ == "__main__":
    GameAgent().run()
```

## 五、合规边界：哪些能做、哪些别碰

### 可以做（本系列全部）

```
✔ 自建游戏（Pygame 沙盒）
✔ 开源单机游戏（并遵循其许可证）
✔ 纯屏幕识别 + 键鼠模拟（不读内存）
✔ 学习、研究、个人实验
```

### 不要做（红线）

```
✘ 联机竞技/网游（违反 ToS，可能封号）
✘ 读取/修改游戏进程内存（破坏系统/违法）
✘ 注入 DLL / 修改客户端（逆向破解范畴）
✘ 用于牟利的外挂销售（非法经营罪）
✘ 绕过正版验证/DRM（侵犯版权）
```

### 一句话原则

> **"看屏幕、按键盘"可以；"拆程序、改内存"不行；商业网游一律不碰。**

## 六、进阶方向（都合法）

```
1. 强化学习：DQN 从"内部状态"升级到"画面帧"（CNN）
2. 行为树：复杂任务编排（收集 → 合成 → 售卖）
3. 多代理：多角色协作（输出 → 聊天 → 分工）
4. 开源游戏适配：把 vision/hands 适配到开源单机（合法）
5. 自动测试：把"游戏自动化"用于游戏 QA 测试（行业刚需）
```

> 游戏公司 QA 部门很欢迎"自动化测试机器人"，这是合法且高价值的方向。

## 六、常见问题 FAQ

| 问题 | 回答 |
|------|------|
| 识别不准？ | 调 HSV 范围/模板阈值，缩小截屏区域 |
| 跑得慢？ | mss + 降分辨率 + 只截窗口 |
| 点击错位？ | 用 ScreenMapper 换算窗口偏移 |
| 状态机太死？ | 上行为树 / 强化学习 |
| 想跑真实游戏？ | 只碰开源单机，先读许可 |
