# 强化学习：用 DQN 训练 AI 自己学会打怪

> 前面都是" 写死规则"，这一篇升级：**让 AI 自己从试错中学会打怪**。用最经典的 **DQN（Deep Q-Network）** 在 Pygame 沙盒里训练一个自动打怪代理——给奖励，它自己就会学。

## 一、强化学习 30 秒入门

强化学习 = 智能体通过"试错 + 奖励"学策略：

```
状态 s → 智能体 → 动作 a → 环境 → 新状态 s' + 奖励 r
```

| 概念 | 本沙盒例子 |
|------|-----------|
| 状态 s | 玩家坐标、最近怪物距离、血量 |
| 动作 a | 上/下/左/右/攻击/拾取 |
| 奖励 r | 打中 +10、捡金币 +5、死亡 -50 |
| 策略 π | 看到怪近了就攻击 |

## 二、DQN 核心思想

用神经网络逼近 Q 值（状态-动作价值）：

```
Q(s, a) = 在状态 s 采取动作 a 能获得的期望总回报
```

训练目标：让 Q 网络预测越来越准：

```
loss = (r + γ * max_a' Q(s', a') - Q(s, a))²
```

```python
import gymnasium as gym
from gymnasium import spaces

class LootEnv(gym.Env):
    def __init__(self):
        super().__init__()
        # 动作：0上 1下 2左 3右 4攻击 5拾取
        self.action_space = spaces.Discrete(6)
        # 状态：玩家 x,y + 最近怪 x,y + 最近掉落 x,y + 血量
        self.observation_space = spaces.Box(
            low=0, high=800, shape=(7,), dtype=np.float32)

    def reset(self):
        self.player = Player()
        self.monsters = [Monster() for _ in range(4)]
        return self._obs(), {}

    def step(self, action):
        # 执行动作
        if action == 0: self.player.y -= 1
        elif action == 1: self.player.y += 1
        elif action == 2: self.player.x -= 1
        elif action == 3: self.player.x += 1
        elif action == 4: self.attack()
        elif action == 5: self.loot()

        reward = self._calc_reward()
        done = self.player.hp <= 0
        return self._obs(), reward, done, False, {}

    def _obs(self):
        m = self._nearest_monster()
        return np.array([
            self.player.x / 800, self.player.y / 600,
            (m.x - self.player.x) / 800,
            (m.y - self.player.y) / 600,
            self.player.hp / 100, 1 if self._near_drop() else 0
        ], dtype=np.float32)
```

## 四、DQN 网络（PyTorch）

```python
import torch
import torch.nn as nn

class DQN(nn.Module):
    def __init__(self, obs_dim, n_actions):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, n_actions)
        )

    def forward(self, x):
        return self.net(x)
```

## 五、训练主循环

```python
import random
from collections import deque

def train():
    env = GameEnv()
    dqn = DQN(6, 6)
    target = DQN(6, 6)          # 目标网络
    target.load_state_dict(dqn.state_dict())
    optimizer = torch.optim.Adam(dqn.parameters(), lr=1e-3)
    replay = deque(maxlen=10000)
    gamma, eps = 0.95, 1.0

    for episode in range(500):
        obs, _ = env.reset()
        total = 0
        while True:
            # ε-贪心：探索或利用
            if random.random() < eps:
                action = random.randint(0, 5)
            else:
                with torch.no_grad():
                    q = dqn(torch.tensor(obs).float())
                    action = q.argmax().item()

            obs2, reward, done, _, _ = env.step(action)
            replay.append((obs, action, reward, obs2, done))
            total += reward
            obs = obs2

            # 训练（采样小批量）
            if len(replay) > 256:
                batch = random.sample(replay, 64)
                train_step(dqn, target, optimizer, batch, gamma)

            if done:
                break

        # 每 10 局同步目标网络
        if episode % 10 == 0:
            target.load_state_dict(dqn.state_dict())
        eps = max(0.05, eps * 0.99)     # 逐渐少探索
        print(f"ep {episode}: reward={total:.0f} eps={eps:.2f}")
```

## 六、训练效果观察

- 前期：随机乱跑、掉血 → 负奖励
- 中期：学会"接近怪" → 偶尔攻击
- 后期：血量安全时主动打怪、残血逃跑

> 关键：**奖励设计决定行为**。想让 AI 学会打怪，就给攻击成功高奖励；想让 AI 学会卖东西，就把"背包满→卖出"设为奖励。
